## Capacidades de Auditoria de Metadatos y Snippets Sociales

* **Revision de Titulos y Descripciones**: Comprobacion de longitud ideal para busquedas en dispositivos moviles y escritorio.
* **Protocolo Open Graph**: Validacion de etiquetas sociales para previsualizaciones en aplicaciones de mensajeria y redes.
* **Twitter Cards y Medios**: Auditoria de formato de tarjetas sociales y dimensiones de imagenes asociadas.
* **Directivas de Rastreabilidad**: Analisis de meta robots y canonicalizacion perimetral.
* **Metrica de Calidad Semantica**: Calificacion de 0 a 100 con recomendaciones concretas de redaccion tecnica.

***

## Instalacion y Ejecucion

Requiere Python 3.8 o superior con biblioteca estandar.

```bash
git clone https://github.com/TAVARDT-Mexico/meta-tags-inspector-mx.git
cd meta-tags-inspector-mx
python meta_inspector.py ejemplo.mx
```

Para salida en formato JSON:

```bash
python meta_inspector.py ejemplo.mx -json
```
